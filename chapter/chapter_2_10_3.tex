\section{Introduction}

Reference: \href{https://youtu.be/TkwXa7Cvfr8?si=V8cJG_DQAoA2fndE}{Watching Neural Networks Learn}\\

An \gls{AI_NN} is a \textit{non-linear mathematical tool} intended to simulate the human brain process by using simple units called artificial neurons arranged in structures known as layers.
\begin{center}
	An \gls{AI_NN} is a \textit{universal function approximator}. They are machines that create functions.
\end{center}

This non-linear mathematical tool can also be understood as a \textit{universal function approximator}. The \textit{Universal Approximation Theorem} states that \gls{AI_NN} with infinite neurons can approximate any function given the right weights. How to achieve this or how to come closer should be the objective of this segment. For example, the layer architecture, the activation function, and preparing the data are relevant topics to consider for finding the global minimum.

\paragraph{Different ways to look at it}
Many mathmatical field are in interplay when it comes to a \gls{AI_NN}.\\

Linear Algebra is mostly used when it comes to computing information though the network. Graph Theory can also be used to to the same thing, but is mostly considered when it comes to analyzing the structure of the neural network. 

\begin{description}
	\item[Linear Algebra] \glspl{AI_NN} can be represented using matrices and vectors, where each neuron's input and output can be described as linear combinations of the inputs with corresponding weights. Matrix operations such as multiplication, addition, and transposition are fundamental in understanding how information flows through the network during forward and backward propagation.
	\item[Graph Theory] \glspl{AI_NN} can be represented as directed graphs, where neurons correspond to nodes and connections between neurons correspond to edges. Graph theory concepts are useful for analyzing the structure of neural networks, including connectivity patterns and network architectures.
\end{description}

Given a certain structure of the network \textit{optimisation} with main tool from \textit{calculus}: \textit{gradient descent} is used to find the parameter that reduces the loss function.\footnote{
	While calculus and optimization are related and often used together in the context of machine learning and neural networks, they are distinct mathematical concepts with different focuses.
}

\begin{description}
	\item[Optimization] \gls{AI_NN} are trained by optimizing a loss function with respect to the network's parameters. Optimization theory provides a framework for selecting appropriate optimization algorithms, tuning hyperparameters, and understanding convergence properties. While calculus provides the mathematical framework for computing gradients and understanding the behavior of optimization algorithms, optimization theory encompasses a wider range of techniques beyond calculus, such as convex optimization, linear programming, and heuristic algorithms.
	\item[Calculus (Optimization)] Calculus is essential for optimizing the parameters (weights and biases) of \gls{AI_NN} through techniques like gradient descent and its variants. Understanding derivatives is crucial for computing gradients, which indicate how the loss function changes with respect to changes in the network's parameters. Calculus helps in finding the direction and rate of change that minimizes or maximizes a function, which is crucial for training neural networks to minimize the loss function.
\end{description}

The field of \textit{probability and statistics} as well as \textit{information theory} are used for multiple aspects of \glspl{AI_NN}. For example the former can be used to preparing or preprocessing of data, model evaluation and bringing into context the uncertainty in predictions. The later will also be used for finding the features in the dataset as well as analysing the information flow inside a \gls{AI_NN}.

\begin{description}
	\item[Probability and Statistics] ANNs can be viewed as probabilistic models, especially in the context of Bayesian neural networks, where uncertainty is explicitly modeled. Statistical techniques are used for data preprocessing, model evaluation, and uncertainty estimation in predictions.
	\item[Information Theory] Information theory concepts, such as entropy and mutual information, can be used to analyze the information flow within neural networks. Compression techniques inspired by information theory, such as autoencoders, are used for feature extraction and dimensionality reduction.
\end{description}

The field of \textit{functional analysis} provides the tools to analyze the natrue of the universal function approximator, called \gls{AI_NN}.

\begin{description}
	\item[Functional Analysis] \glspl{AI_NN} can be viewed as function approximators, and functional analysis provides tools for analyzing the properties of these approximations. Understanding function spaces and convergence properties is relevant when studying the expressive power and generalization abilities of neural networks. 
\end{description}

\paragraph{Curve Fitting with Neural Networks}

One of the core capabilities of artificial neural networks (ANNs) is \textbf{curve fitting} — the process of adjusting internal parameters (weights and biases) such that the network’s output closely matches a desired target function. This ability lies at the heart of training in machine learning: fitting a model to data.

A neural network learns to approximate a function $f(x)$ by minimizing a loss function, often using the method of \textit{gradient descent}, implemented via the \textit{backpropagation} algorithm. Over successive iterations, the network adjusts its parameters to reduce the difference between its output and the target values.

\vspace{1em}
\noindent
To illustrate this, consider a dataset where the target outputs $\vec{y}$ follow a sinusoidal curve. Initially, the output of the neural network may appear linear and poorly aligned with the target.

\begin{figure}[H]
	\centering
	\includegraphics[scale=0.2]{attachment/chapter_AML/Scc032}
	\caption{Initial state: network output does not match target}
\end{figure}

As training proceeds, the weights are adjusted iteratively. The output begins to more closely follow the sinusoidal shape of the target curve, reducing the loss.

\begin{figure}[H]
	\centering
	\includegraphics[scale=0.2]{attachment/chapter_AML/Scc033}
	\caption{After some training: network output approximates the target better}
\end{figure}

Eventually, with sufficient training, the network approximates the desired function with high accuracy. This behavior is formalized by the \textbf{Universal Approximation Theorem}, which states that a feedforward neural network with at least one hidden layer can approximate any continuous function on a compact domain, given sufficient capacity and proper parameters.

\begin{figure}[H]
	\centering
	\includegraphics[scale=0.2]{attachment/chapter_AML/Scc034}
	\caption{A neural network as a universal function approximator: $f(x) \approx NN(x)$}
\end{figure}

This curve fitting process is general and not limited to any specific type of function. It forms the foundation for using neural networks in regression tasks, signal modeling, and even classification by projecting decision boundaries.

	\item Each node combines an \textit{affine linear function} and a nonlinear \textit{activation function}.

\glspl{AI_NN} are nonlinear mathematical tools\footnote{However, there is a possibility to design it so that it can be a linear function.}, intended to mimic human brain processes by stacking simple neurons together. The simplest unit of an \gls{AI_NN} is called a \textit{Neuron}. They are structured in \textit{layers}. The learning process for humans is called training, while for \glspl{AI_NN} it is referred to as training.\\

A layer can be represented as a \textit{parameterized function}. From the perspective of a directed graph, each node can be represented as an \textit{affine linear function}. The combination of each layer can be understood as a new \textit{affine linear function} [for a given neuron].

The nonlinear quality of an \gls{AI_NN} arises from the \textit{activation function}.

\paragraph{Transformer Function} Given the input $x^t$\footnote{
	The initial input of the layer can be understood as \textit{features}, which can be represented as a vector  $x^t = (x_1, \dots, x_n)$
}. These are processed in a \textit{neuron} through \textit{weights} $w_i, i=1,\dots, n$, producing $z$, which then produces the final output $y$ through some function $\phi$, $\phi(z) = y$.

The output $z$ is the result of processing the $n-x_i$ weightily:
\begin{align}
z &= (w_1, \dots, w_n) \left(\begin{matrix}
		x_1 \\
		\vdots \\
		x_n
	\end{matrix} \right) + b \\
  &= \sum_{i=1}^n x_i\cdot w_i +b = w^t x + b,
\end{align}
where $b$ is called \textit{bias}. This should give the system more flexibility by imitating a human filter. This \textit{affine function} can be changed into a linear function, where $b$ is set as $w_0$ and $x_0 = 1$:
\begin{align}
z &= (w_0, \dots, w_n) \left(\begin{matrix}
		x_0 = 1 \\
		\vdots \\
		x_n
	\end{matrix} \right) \\
  &= \sum_{i=0}^n x_i\cdot w_i = w^t x.
\end{align}
To avoid the notation of the transpose, it can be represented by $w\cdot x$.

However, depending on the needs, these processes can be viewed as affine or linear functions. In either case, processing the input $x_i$ resulting in $z$ is called a \textbf{transfer function}. Depending on the needs different transformers can be used. The most popular or most used is the sum operator $\sum$:

As discussed before, the entirety of \glspl{AI_NN} can be understood as mathematical functions with an input $x$ and an output $y$.

\begin{align}
	f_{NN}(x) = y
\end{align} 

To combine each neuron, the output of each neuron is sent to all neurons in the next layer. This forwarding of information is called \textit{feed-forward}. From the perspective of a function, this is called \textit{verschachteln}. Each neuron in each layer (hidden layer) receives the output of the previous neurons. This neuron is then called a \gls{MLP}.

\begin{Definition}{Multilayer Perceptron}
	
	A \gls{MLP} is a function $f_l:\R^n \rightarrow \R$. It is called an $n-L-m$ perceptron, with $n$ inputs, $L$ hidden layers, and $m$ outputs.
	
	\begin{align}
		y = f^{(l)}(\vec{x}) = f_{l-1}\left(f_{l-2}\left(...\left(f_{0}(\vec{x})\right)\right)\right).
	\end{align}
	
	Where $f^{(i)}(\vec{z}) \stackrel{def}{=} \phi_l\left( \Matrix[W]^{(l)}\vec{z} + b^{(l)}\right)$.
\end{Definition}

A feedforward neural network is composed of multiple layers of neurons, where each layer transforms the outputs of the previous one. The architecture typically includes:

\begin{itemize}
    \item \textbf{Input Layer:} Accepts the input features \( x_1, x_2, \ldots, x_n \)
    \item \textbf{One or more Hidden Layers:} Perform transformations via weighted sums and activation functions
    \item \textbf{Output Layer:} Produces the final prediction
\end{itemize}

Each layer \( l \geq 1 \) is computed as a function of the previous layer's outputs:
\begin{align}
	y^{(l)} = g^{(l)}\left(W^{(l)} y^{(l-1)} + b^{(l)}\right)	
\end{align}
where:
\begin{itemize}
    \item \( W^{(l)} \): weight matrix for layer \( l \)
    \item \( b^{(l)} \): bias vector for layer \( l \)
    \item \( g^{(l)} \): activation function (e.g., ReLU, sigmoid)
    \item \( y^{(l-1)} \): output from previous layer
\end{itemize}

The process starts with the input vector \( x \), which is treated as the output of layer 0:
\[
x^{(0)} = [x_1, x_2, \ldots, x_n]^T
\]

This allows a unified formulation across all layers.

\paragraph*{Why the Input Layer is Indexed as Layer 0}

In a multilayer perceptron (MLP), the architecture is functionally designed: each layer is constructed as a function of the previous layer. The goal is not to pass data through layers in a procedural sense, but to define a composition of functions that progressively transform the input into the desired output.

\medskip

The input variables \( x_i \) are mapped to \( x_i^{(0)} \), indicating that they belong to \emph{layer 0}. This layer, however, does not perform any computation. Instead, it serves as the initial input to the network---a semantic starting point. The actual construction of neurons begins with layer 1.

\medskip

For instance, the output of the first hidden layer is computed as:
\[
y^{(1)} = g^{(1)}\left(W^{(1)} x^{(0)} + b^{(1)}\right),
\]
where \( x^{(0)} \) is the input vector, \( W^{(1)} \) is the weight matrix for layer 1, \( b^{(1)} \) is the bias vector, and \( g^{(1)} \) is the activation function applied element-wise.

\medskip

This functional formulation emphasizes that layer 0 is not an active layer that transforms data, but rather a formally labeled placeholder. It provides a consistent and generalizable framework for expressing all subsequent layers as transformations:
\[
y^{(l)} = g^{(l)}\left(W^{(l)} y^{(l-1)} + b^{(l)}\right), \quad \text{for } l \geq 1.
\]

\medskip

Thus, indexing the input layer as \( l = 0 \) aligns with the functional design of neural networks, where the core focus is on \emph{constructing neurons layer by layer}, not merely passing data forward.

\end{align}

\subsubsection{Softmax}
The softmax activation function most commenly used for the outputlayer. Note in PyTorch the \verb+nn.CrossEntropyLoss+ internally uses the \verb+nn.softmax+. Hence, using it for the output layer would lead to errors.


\paragraph{Classification Setup}

In a multi-class classification problem with $C$ possible classes, the neural network outputs a vector of raw scores (logits):
\[
\mathbf{z} = [z_1, z_2, \dots, z_C] \in \mathbb{R}^{C}
\]
Each $z_i$ corresponds to the score for class $i$. These values are not probabilities—they can be negative, and do not sum to $1$.

\paragraph{From Logits to Probabilities: Softmax}

To convert logits into class probabilities, the \textbf{softmax function} is applied:
\begin{align}
	\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}
\end{align}
This transformation ensures:
\begin{itemize}
	\item \textbf{Non-negativity:} Since $e^{z_i} > 0$ for all $z_i \in \mathbb{R}$, we have $\hat{p}_i > 0$.
	\item \textbf{Normalization:}
	\[
	\sum_{i=1}^C \hat{p}_i = \sum_{i=1}^C \frac{e^{z_i}}{\sum_{j=1}^C e^{z_j}} = \frac{\sum_{i=1}^C e^{z_i}}{\sum_{j=1}^C e^{z_j}} = 1
	\]
\end{itemize}

Therefore, the softmax output $\hat{\mathbf{p}}$ is a valid \textbf{discrete probability distribution} over the $C$ classes.


\paragraph{Cross-Entropy Loss}

Given the true class label $y \in \{0, \dots, C-1\}$, we want the model to assign high probability to the correct class. The \textbf{cross-entropy loss} for one example is defined as:
\begin{align}
	\mathcal{L}(\mathbf{z}, y) = -\log\left( \frac{e^{z_y}}{\sum_{j=1}^{C} e^{z_j}} \right)
	= -z_y + \log\left( \sum_{j=1}^{C} e^{z_j} \right)
\end{align}

This loss penalizes the model for assigning low probability to the true class. The lower the predicted probability for the true class, the higher the loss.


\paragraph{Caution in PyTorch}
In PyTorch, the function \verb+nn.CrossEntropyLoss+ expects the raw logits as input. It automatically applies both:
\begin{itemize}
	\item \verb+nn.LogSoftmax+ (to compute log-probabilities),
	\item \verb+nn.NLLLoss+ (Negative Log Likelihood Loss).
\end{itemize}

This combination is:
\begin{align}
	\texttt{CrossEntropyLoss}(\mathbf{z}, y) = \texttt{NLLLoss}(\log(\texttt{softmax}(\mathbf{z})), y)
\end{align}

\textbf{Important:} If you apply \verb+softmax+ manually before passing the output to \verb+CrossEntropyLoss+, it leads to incorrect results because softmax will be applied \emph{twice}, breaking the numerical stability and the gradient computation.


\section{Concept Logits}
\subsection*{Definition of Logits}

\subsubsection*{Formal Definition}

In machine learning, particularly in classification tasks, the term \textbf{logits} refers to the raw, unnormalized output values of a neural network, typically produced by the final linear layer before any activation function is applied.\\ 

Let the final layer of a neural network be:
\begin{align}
\mathbf{z}^{(l)} = \mathbf{W}^{(l)}  \mathbf{y}^{(l-1)} + \mathbf{b}^{(l)} 
\end{align}

%\begin{align}
%	y^{(l)} = g^{(l)}\left(W^{(l)} y^{(l-1)} + b^{(l)}\right)	
%\end{align}

where:
\begin{itemize}
	\item $\mathbf{y}^{(l-1)} \in \mathbb{R}^d$ is the hidden representation (output of the previous layer),
	\item $\mathbf{W} \in \mathbb{R}^{C \times d}$ is the weight matrix,
	\item $\mathbf{b} \in \mathbb{R}^C$ is the bias vector,
	\item $\mathbf{z}^{(l)} = [z_1^{(l)}, z_2^{(l)}, \dots, z_C^{(l)}]$ is the output vector of size $C$, the number of classes in the last layer.
\end{itemize}

Each $z_i^{(l)}$ is called a \textbf{logit}, and represents the score assigned by the model to class $i$. These logits are not probabilities; they can take any real value (positive or negative).

\subsubsection*{Usage in Classification}

To convert logits into class probabilities, an activation function such as softmax is applied:
\[
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}
\]

However, when using loss functions like \texttt{CrossEntropyLoss}, you should provide the logits directly. These loss functions internally apply softmax in a numerically stable way.

\subsubsection*{Why the Term "Logit"?}

The term "logit" comes from statistics, where the logit function is the log-odds:
\[
\text{logit}(p) = \log\left( \frac{p}{1 - p} \right)
\]
In binary classification, the neural network models the logit directly, which is then passed through a sigmoid function to yield the predicted probability:
\[
p = \sigma(z) = \frac{1}{1 + e^{-z}}
\]

\subsection*{Example: Digit Classification (0 to 9) with Logits vs Softmax}

Suppose we have a neural network classifying digits from 0 to 9 (10 classes), and the correct digit is:
\[
y = 3
\]

\subsubsection*{Model Output: Raw Logits}

The model outputs the following logits (raw scores before activation):
\[
\mathbf{z} = [1.2,\ 0.3,\ -0.8,\ \mathbf{2.5},\ 0.1,\ -1.0,\ 0.4,\ 0.2,\ -0.2,\ 1.0]
\]

Note that class 3 has the highest logit: $z_3 = 2.5$

\subsubsection*{Correct Usage: Raw Logits with \texttt{CrossEntropyLoss}}

\texttt{CrossEntropyLoss} applies softmax internally:
\[
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=0}^{9} e^{z_j}}
\]

Then computes the loss as:
\[
\mathcal{L} = -\log \left( \text{softmax}(z_3) \right)
\]

This ensures numerical stability and correct gradient computation.

\subsubsection*{Incorrect Usage: Softmax Output with \texttt{CrossEntropyLoss}}

If we apply softmax manually:
\[
\hat{p}_i = \frac{e^{z_i}}{\sum_{j=0}^{9} e^{z_j}}
\Rightarrow
\hat{p} = [0.100,\ 0.041,\ 0.016,\ \mathbf{0.506},\ 0.034,\ 0.014,\ 0.045,\ 0.037,\ 0.025,\ 0.181]
\]

Then pass these into \texttt{CrossEntropyLoss}, the function will incorrectly interpret them as logits. It will again apply log-softmax, making the loss computation:
\[
\mathcal{L}_{\text{wrong}} = -\log \left( \log(\hat{p}_3) \right)
\]

This yields completely incorrect loss values and gradients, and can break training.



\subsubsection*{Summary}

\begin{itemize}
	\item Logits are the raw outputs of the final linear layer in a neural network.
	\item They represent class scores, not probabilities.
	\item They are used as inputs to activation functions like softmax or sigmoid.
	\item They should be passed directly to loss functions like \texttt{CrossEntropyLoss} or \texttt{BCEWithLogitsLoss}.
\end{itemize}
